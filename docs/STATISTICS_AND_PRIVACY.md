# إحصاء تثبيت التطبيق والخصوصية

## ما الذي يحسبه النظام

- **الزوار الفريدون:** متصفحات وافقت صراحة على التحليلات وحصلت على معرف UUID عشوائي محلي.
- **مثبتو الأداة:** معرفات وافقت على التحليلات وسجلت حدث `appinstalled` أو فتحت الموقع بوضع التطبيق المستقل.
- **نسبة التثبيت:** عدد المثبتين المقيد مرة واحدة مقسومًا على عدد الزوار الفريدين، وبحد أقصى 100%.

تعرض لوحة الإدارة العدد والنسبة ضمن المؤشرات الرئيسية.

## الحماية والحدود

- لا يستخدم البريد أو الاسم أو UID الحساب أو بصمة الجهاز.
- لا ينشأ المعرف قبل موافقة التحليلات.
- يرسل UUID للخادم، ثم يحوله الخادم إلى SHA-256 قبل حفظ علامة منع التكرار في Firestore.
- قواعد Firestore تمنع العميل من قراءة مجموعات علامات المنع أو الكتابة فيها مباشرة.
- إلغاء بيانات الموقع أو استخدام متصفح آخر قد ينشئ معرفًا جديدًا؛ لذلك الرقم تقديري لعمليات تثبيت المتصفحات، وليس سجلًا مضمونًا لكل جهاز أو شخص.
- المتصفح لا يوفر للموقع قائمة كاملة بجميع الأجهزة التي ثبتت التطبيق. لهذا لا يمكن حساب التثبيتات السابقة قبل إطلاق القياس.
- هذا المقياس تشغيلي ولا يصلح وحده للفوترة الإعلانية أو إثبات عدد أشخاص حقيقيين.

## اختبار الخصوصية

1. بدون موافقة التحليلات: لا يوجد `date_tools_anonymous_analytics_id_v1` ولا طلب إحصائي يحمل `visitorId`.
2. بعد الموافقة: ينشأ UUID عشوائي صالح فقط.
3. تكرار فتح التطبيق المستقل بالمعرف نفسه لا يزيد `pwaInstalls` مرة ثانية.
4. القيم المشوهة أو البريد أو مسار مثل `../admin` ترفض ولا تستخدم كمعرف مستند.
